
# Python — Fundamentos e POO

Repositório dedicado aos meus estudos de Python,
com exercícios práticos de Programação Orientada a Objetos (POO).

## Conteúdos estudados

- Classes e objetos
- Atributos e métodos
- Construtor `__init__`
- Parâmetro `self`
- Condicionais
- Manipulação de estados internos
- Operações matemáticas e validação de dados

## Organização

- `01_classe_aluno.py`: cadastro e aprovação de alunos.
- `02_cartao_estudante.py`: recarga e uso de saldo.
- `03_sistema_biblioteca.py`: empréstimo e devolução de livros.

## Como executar

É necessário ter Python 3 instalado.

No terminal, execute:

python3 exercicios/03_sistema_biblioteca.py

## Objetivo

Consolidar os fundamentos da linguagem Python
e desenvolver a capacidade de resolver problemas
por meio da Programação Orientada a Objetos.
